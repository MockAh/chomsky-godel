§ 1Álgebra booleana

El álgebra de Boole sobre {0,1} es el caso más pequeño de una estructura que ya conocías: 𝒫(X) con unión, intersección y complemento.

Ejercicio 1 · evaluación
Evalúa ¬(x · ¬y) + (¬x · y) para x = 1, y = 0
Ver solución
¬y = ¬0 = 1 x · ¬y = 1 · 1 = 1 → ¬(x · ¬y) = 0 ¬x = 0 → ¬x · y = 0 · 0 = 0 Resultado: 0 + 0 = 0
Ejercicio 2 · tabla de verdad
Tabla completa de ¬(x · ¬y) + (¬x · y): ¿qué operación es?
Ver solución
xyresultado
001
011
100
111

Es la implicación material x → y: solo es falsa cuando el antecedente es verdadero y el consecuente falso.

Ejercicio 3 · demostración
Demuestra ¬(x · ¬y) + (¬x · y) = ¬x + y solo con axiomas
Ver solución
¬(x · ¬y) + (¬x · y) = (¬x + y) + (¬x · y) De Morgan; ¬¬y = y = ¬x + y · (1 + ¬x) factorizar y = ¬x + y · 1 1 + A = 1 = ¬x + y ∎
Ejercicio 4
Expresa XOR con AND, OR y NOT
Ver solución
XOR(x, y) = (x · ¬y) + (¬x · y)

§ 2Completitud funcional

El hecho central
NAND basta

Con suficientes compuertas NAND se construye cualquier función booleana. Por eso NAND es la pieza fundamental del hardware.

Ejercicio 5
Expresa NOT(x) solo con NAND
Ver solución
NOT(x) = NAND(x, x) = ¬(x · x) = ¬x

Paso clave: idempotencia, x · x = x.

Ejercicio 6
Expresa AND(x, y) solo con NAND y verifica (1,1) y (1,0)
Ver solución
AND(x, y) = NOT(NAND(x, y)) = NAND(NAND(x, y), NAND(x, y)) (1,1): NAND(0, 0) = 1 ✓ (1,0): NAND(1, 1) = 0 ✓
Ejercicio 7
Expresa NOR(x, y) solo con NAND
Ver solución
NOR(x, y) = ¬(x + y) = NAND(x + y, x + y) con OR(x, y) = NAND(NAND(x,x), NAND(y,y)): NOR(x, y) = NAND( NAND(NAND(x,x), NAND(y,y)), NAND(NAND(x,x), NAND(y,y)) )

§ 3Representación posicional

Toda base b evalúa el mismo polinomio N = Σ dᵢ·bⁱ. Cuando una base es potencia de otra (16 = 2⁴, 8 = 2³), convertir es concatenar bloques, sin aritmética.

Ejercicio 8
Convierte 0xA3 a binario sin pasar por decimal
Ver solución
A → 1010, 3 → 0011 0xA3 = 1010 0011
Ejercicio 9
0xA3 en decimal, y verificación por el binario
Ver solución
Por hex: 10·16 + 3 = 163 Por binario: 128 + 32 + 2 + 1 = 163 ✓
Ejercicio 10
¿Cuántos bits por dígito octal? ¿Por qué funciona concatenar?
Ver solución

Tres: 2³ = 8 combinaciones, exactamente los dígitos {0..7}.

Para un octal XY: XY = X·2³ + Y. Multiplicar por 2³ desplaza los bits de X a las posiciones 2⁵, 2⁴, 2³, sin traslapar las de Y. Regla general: si b = 2ᵏ, cada dígito consume k bits.

Ejercicio 11
Si 'A' = 0x41 y las letras son consecutivas, ¿cuánto vale 'G'?
Ver solución
'A' = 0x41, 'B' = 0x42, …, 'G' = 0x47 4 → 0100, 7 → 0111 → 'G' = 0100 0111

§ 4Suma, resta y complemento a dos

La máquina solo sabe sumar. Restar es sumar el complemento a dos: invertir los bits y sumar 1. El acarreo que no cabe se tira: es aritmética en ℤ/2ⁿℤ.

Ejercicio 12
Suma 0xA3 + 0x1D en binario
Ver solución
1010 0011 (0xA3 = 163) + 0001 1101 (0x1D = 29) = 1100 0000 (0xC0 = 192) ✓
Ejercicio 13
0xC0 − 0x1D con préstamo directo
Ver solución
1100 0000 − 0001 1101 bits 0 a 5 piden préstamo en cadena; el bit 6 lo salda = 1010 0011 = 0xA3 = 163 ✓
Ejercicio 14
0xC0 − 0x1D vía complemento a dos
Ver solución
0x1D = 0001 1101 → invertir 1110 0010 → +1 → 1110 0011 (= −29) 1100 0000 + 1110 0011 = 1 1010 0011 el 9.º bit no cabe en 8: se descarta = 1010 0011 = 163 ✓
Ejercicio 15
Rango de 8 bits en complemento a dos
Ver solución
0111 1111 = +127, 1000 0000 = −128 −2⁷ ≤ x ≤ 2⁷ − 1; con n bits: −2ⁿ⁻¹ ≤ x ≤ 2ⁿ⁻¹ − 1
Ejercicio 16
Complemento a dos de 1000 0000 (−128)
Ver solución
1000 0000 → invertir 0111 1111 → +1 → 1000 0000

La negación tiene un punto fijo no trivial: no existe +128 en 8 bits.

§ 5Texto es número

Un carácter es un code point (un número en el catálogo Unicode); la codificación (UTF-8, UTF-32) decide cuántos bytes ocupa.

Ejercicio 17
¿Cuánto pesa 'HOLA' en UTF-8 y en UTF-32?
Ver solución
UTF-8: 4 × 1 byte = 4 bytes UTF-32: 4 × 4 bytes = 16 bytes

Factor 4 a favor de UTF-8 para texto mayormente ASCII.

§ 6Palabra y direcciones

La memoria se direcciona por byte, y una dirección cabe en una palabra: 64 bits.

Ejercicio 18
¿Cuántas direcciones distintas hay con 64 bits?
Ver solución
2⁶⁴ direcciones atajo: 2¹⁰ ≈ 10³ 2⁶⁴ = 2⁶⁰ · 2⁴ ≈ 10¹⁸ · 16 ≈ 1.6 × 10¹⁹
Ejercicio 19
2⁶⁴ bytes en gigabytes (1 GB ≈ 2³⁰ bytes)
Ver solución
2⁶⁴ / 2³⁰ = 2³⁴ GB ≈ 10⁹ · 16 ≈ 1.6 × 10¹⁰ GB

Unos 16 exabytes: mucho más de lo que tiene cualquier RAM real.

§ 7Del interruptor a la compuerta

Un transistor es un interruptor. En serie computan AND; en paralelo, OR; uno configurado al revés es NOT.

Ejercicio 20
¿Cuántos transistores mínimo para NAND, y en qué disposición?
Ver solución

Tres. Dos en serie computan A · B; el tercero, como NOT, va al final e invierte la salida. La posición del NOT importa: al principio produciría ¬A · B, otra función.

NotaEn CMOS real, NAND se construye directo con cuatro transistores, sin encadenar AND + NOT. Es una razón por la que NAND es la pieza fundamental.
Ejercicio 21
Construye NOR con la misma lógica
Ver solución

Óptima, tres: dos en paralelo computan A + B; el tercero invierte. Es la imagen especular de NAND.

Vía De Morgan, cuatro: ¬(A + B) = ¬A · ¬B: dos NOT y un AND en serie. Funciona, con un transistor de más.

Expresiones algebraicamente equivalentes pueden tener costos físicos distintos: de eso trata la minimización lógica.
