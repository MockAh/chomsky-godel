§ 1Boolean algebra

Boolean algebra over {0,1} is the smallest case of a structure you already knew: 𝒫(X) with union, intersection and complement.

Exercise 1 · evaluation
Evaluate ¬(x · ¬y) + (¬x · y) for x = 1, y = 0
See solution
¬y = ¬0 = 1 x · ¬y = 1 · 1 = 1 → ¬(x · ¬y) = 0 ¬x = 0 → ¬x · y = 0 · 0 = 0 Result: 0 + 0 = 0
Exercise 2 · truth table
Full table of ¬(x · ¬y) + (¬x · y): which operation is it?
See solution
xyresult
001
011
100
111

It is material implication x → y: it is false only when the antecedent is true and the consequent false.

Exercise 3 · proof
Prove ¬(x · ¬y) + (¬x · y) = ¬x + y using only axioms
See solution
¬(x · ¬y) + (¬x · y) = (¬x + y) + (¬x · y) De Morgan; ¬¬y = y = ¬x + y · (1 + ¬x) factor out y = ¬x + y · 1 1 + A = 1 = ¬x + y ∎
Exercise 4
Express XOR with AND, OR and NOT
See solution
XOR(x, y) = (x · ¬y) + (¬x · y)

§ 2Functional completeness

The central fact
NAND is enough

With enough NAND gates any Boolean function can be built. That is why NAND is the fundamental building block of hardware.

Exercise 5
Express NOT(x) using only NAND
See solution
NOT(x) = NAND(x, x) = ¬(x · x) = ¬x

Key step: idempotence, x · x = x.

Exercise 6
Express AND(x, y) using only NAND and check (1,1) and (1,0)
See solution
AND(x, y) = NOT(NAND(x, y)) = NAND(NAND(x, y), NAND(x, y)) (1,1): NAND(0, 0) = 1 ✓ (1,0): NAND(1, 1) = 0 ✓
Exercise 7
Express NOR(x, y) using only NAND
See solution
NOR(x, y) = ¬(x + y) = NAND(x + y, x + y) with OR(x, y) = NAND(NAND(x,x), NAND(y,y)): NOR(x, y) = NAND( NAND(NAND(x,x), NAND(y,y)), NAND(NAND(x,x), NAND(y,y)) )

§ 3Positional representation

Every base b evaluates the same polynomial N = Σ dᵢ·bⁱ. When one base is a power of another (16 = 2⁴, 8 = 2³), converting is concatenating blocks, with no arithmetic.

Exercise 8
Convert 0xA3 to binary without going through decimal
See solution
A → 1010, 3 → 0011 0xA3 = 1010 0011
Exercise 9
0xA3 in decimal, and a check through binary
See solution
Via hex: 10·16 + 3 = 163 Via binary: 128 + 32 + 2 + 1 = 163 ✓
Exercise 10
How many bits per octal digit? Why does concatenating work?
See solution

Three: 2³ = 8 combinations, exactly the digits {0..7}.

For an octal XY: XY = X·2³ + Y. Multiplying by 2³ shifts the bits of X to positions 2⁵, 2⁴, 2³, without overlapping those of Y. General rule: if b = 2ᵏ, each digit takes k bits.

Exercise 11
If 'A' = 0x41 and the letters are consecutive, what is 'G'?
See solution
'A' = 0x41, 'B' = 0x42, …, 'G' = 0x47 4 → 0100, 7 → 0111 → 'G' = 0100 0111

§ 4Addition, subtraction and two's complement

The machine only knows how to add. Subtracting is adding the two's complement: invert the bits and add 1. The carry that does not fit is thrown away: it is arithmetic in ℤ/2ⁿℤ.

Exercise 12
Add 0xA3 + 0x1D in binary
See solution
1010 0011 (0xA3 = 163) + 0001 1101 (0x1D = 29) = 1100 0000 (0xC0 = 192) ✓
Exercise 13
0xC0 − 0x1D with direct borrowing
See solution
1100 0000 − 0001 1101 bits 0 to 5 borrow in a chain; bit 6 settles it = 1010 0011 = 0xA3 = 163 ✓
Exercise 14
0xC0 − 0x1D via two's complement
See solution
0x1D = 0001 1101 → invert 1110 0010 → +1 → 1110 0011 (= −29) 1100 0000 + 1110 0011 = 1 1010 0011 the 9th bit does not fit in 8: it is discarded = 1010 0011 = 163 ✓
Exercise 15
Range of 8 bits in two's complement
See solution
0111 1111 = +127, 1000 0000 = −128 −2⁷ ≤ x ≤ 2⁷ − 1; with n bits: −2ⁿ⁻¹ ≤ x ≤ 2ⁿ⁻¹ − 1
Exercise 16
Two's complement of 1000 0000 (−128)
See solution
1000 0000 → invert 0111 1111 → +1 → 1000 0000

Negation has a non-trivial fixed point: there is no +128 in 8 bits.

§ 5Text is a number

A character is a code point (a number in the Unicode catalogue); the encoding (UTF-8, UTF-32) decides how many bytes it takes.

Exercise 17
How much does 'HOLA' weigh in UTF-8 and in UTF-32?
See solution
UTF-8: 4 × 1 byte = 4 bytes UTF-32: 4 × 4 bytes = 16 bytes

A factor of 4 in favour of UTF-8 for mostly-ASCII text.

§ 6Word and addresses

Memory is addressed by byte, and an address fits in a word: 64 bits.

Exercise 18
How many distinct addresses are there with 64 bits?
See solution
2⁶⁴ addresses shortcut: 2¹⁰ ≈ 10³ 2⁶⁴ = 2⁶⁰ · 2⁴ ≈ 10¹⁸ · 16 ≈ 1.6 × 10¹⁹
Exercise 19
2⁶⁴ bytes in gigabytes (1 GB ≈ 2³⁰ bytes)
See solution
2⁶⁴ / 2³⁰ = 2³⁴ GB ≈ 10⁹ · 16 ≈ 1.6 × 10¹⁰ GB

About 16 exabytes: far more than any real RAM has.

§ 7From switch to gate

A transistor is a switch. In series they compute AND; in parallel, OR; one wired the other way round is NOT.

Exercise 20
What is the minimum number of transistors for NAND, and in what arrangement?
See solution

Three. Two in series compute A · B; the third, as a NOT, goes at the end and inverts the output. The position of the NOT matters: at the start it would produce ¬A · B, a different function.

NoteIn real CMOS, NAND is built directly with four transistors, without chaining AND + NOT. That is one reason NAND is the fundamental building block.
Exercise 21
Build NOR with the same logic
See solution

Optimal, three: two in parallel compute A + B; the third inverts. It is the mirror image of NAND.

Via De Morgan, four: ¬(A + B) = ¬A · ¬B: two NOTs and an AND in series. It works, with one extra transistor.

Algebraically equivalent expressions can have different physical costs: that is what logic minimization is about.
